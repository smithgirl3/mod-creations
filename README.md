# Cozy Coffee Shop — Procedural Blender Environment

Procedural **Blender 5.2.0** Python pipeline that builds a hyperrealistic rainy-evening coffee shop and exports it for **Unity**.

## Run

1. Open `CREATE_COZY_COFFEE_SHOP.py` in Blender 5.2 → **Run Script**
2. Or: `blender --background --python CREATE_COZY_COFFEE_SHOP.py`

See [`coffee_shop_environment/README.md`](coffee_shop_environment/README.md) for architecture, texture folders, and Unity import notes.

## Output

`coffee_shop_environment/export/` → FBX, GLB, textures, Unity sidecar JSON.
